# 企业考勤排班管理系统企业能力

## 领域覆盖

- **考勤组**：按法人、地点、部门、岗位配置日历和打卡规则
- **班次规则**：设置弹性、跨天、轮班、休息、迟到和早退规则
- **智能排班**：支持周期班次、批量排班、换班和冲突检查
- **打卡记录**：接收移动端、门禁、考勤机和补签数据
- **休假出差**：管理假期额度、请假、出差、销假和审批结果
- **加班管理**：执行申请、审批、调休或加班费结转
- **异常处理**：闭环缺卡、迟到、早退、跨区和设备异常
- **工时核算**：按项目、成本中心和工作日历汇总有效工时
- **考勤月结**：执行确认、锁定、重开、薪资推送和审计

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业考勤排班管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `PAYROLL`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
